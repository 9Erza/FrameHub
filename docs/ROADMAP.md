# Roadmap

## Implemented

- Game library scanning, CPU profiles, profile watcher, Session Optimization, CS2 configuration workflow, optional hardware monitoring, PL/EN UI, logs, tray behavior, and Windows startup configuration.
- FrameHub v0.6 PresentMon Service/API capture and packaging, exact-PID game detection, WPF Capture/History/Compare workflow, frame-time graph, context metadata and local session management.

- Additional game integrations and clearer before/after reporting.
- More safe controls for selected background applications.
- Additional benchmark environment metadata and reporting refinements after v0.6 validation.

## Experimental / Research

- Benchmark comparison methodology and advanced PresentMon/frame-generation research beyond the active v0.6 foundation.
- Additional Windows utilities subject to safety and reversibility review.
