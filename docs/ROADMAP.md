# FrameHub roadmap

## Implemented

- Game library with CPU profile configuration.
- Process and CPU control, saved profiles, profile monitoring, and logs.
- Session Optimization with automatic game detection and safe recovery.
- Optional Hardware Monitor.

## Planned

- Background control for selected non-critical applications.
- System toolkit for safe, reversible Windows utilities.
- Benchmarks and PresentMon-based performance capture.
- Windows tuning with preview, backup, and rollback.

## Experimental / Research

- Before/after optimization reports and frametime analysis.
- Additional game-specific configuration workflows.
- Conservative background-process policies with explicit user review.
