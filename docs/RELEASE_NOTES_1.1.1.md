## English

### FrameHub 1.1.1: interface fixes on top of 1.1.0

A small update with fixes found right after 1.1.0. Install `FrameHub-Setup-1.1.1.exe` over your current FrameHub: settings, Library, profiles, benchmark history and paired devices are kept.

### What's new in 1.1.1

- **Dashboard:** System overview shows each metric as title, value and description, so names are no longer cut off in 1280 px windows.
- **Sidebar:** the profile monitor line updates as soon as a profile is added or enabled.
- **Top CPU processes:** FrameHub itself is left out; the full Processes & CPU table still lists it.
- **Version label:** the version is always read from FrameHub itself.

### Known limitations

The known limitations of [1.1.0](RELEASE_NOTES_1.1.0.md) still apply: EA app and Battle.net games are not discovered automatically, the first opening of Library and Session Optimization takes about 150 ms, and on Windows 10 the window keeps a thin FrameHub-drawn border.

## Polski

### FrameHub 1.1.1: poprawki interfejsu po wydaniu 1.1.0

Mała aktualizacja z poprawkami znalezionymi zaraz po 1.1.0. Zainstaluj `FrameHub-Setup-1.1.1.exe` na obecną instalację: ustawienia, biblioteka, profile, historia benchmarków i sparowane urządzenia zostają.

### Co nowego w 1.1.1

- **Panel główny:** „Stan systemu” pokazuje każdą wartość jako nazwę, wartość i opis, więc nazwy nie są już ucinane w oknie 1280 px.
- **Pasek boczny:** status monitora profili odświeża się od razu po dodaniu lub włączeniu profilu.
- **Najbardziej obciążające procesy:** lista pomija sam FrameHub; pełna tabela w Procesy i CPU nadal go pokazuje.
- **Numer wersji:** zawsze odczytywany z samego FrameHub.

### Znane ograniczenia

Nadal obowiązują znane ograniczenia [1.1.0](RELEASE_NOTES_1.1.0.md): gry z EA app i Battle.net nie są wykrywane automatycznie, pierwsze otwarcie Biblioteki i Optymalizacji sesji trwa ok. 150 ms, a w Windows 10 okno ma cienką ramkę rysowaną przez FrameHub.
