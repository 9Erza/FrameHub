# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop (native WPF); the separate LAN Companion is a web interface.

## Users

PC players managing their games and gaming environment, including users who need
to inspect processes, scheduling, hardware and benchmark results.

## Product Purpose

Bring game discovery, session optimization, process controls and performance
measurement together in a Windows application. Success means users can see
what is happening, choose an action deliberately and recover from a session.

## Operating Context

The desktop application is used alongside games and Windows processes. The
Companion provides a separately authenticated LAN interface. Session changes
and benchmarks are coordinated by the existing application services.

## Capabilities and Constraints

The product includes a game library, session optimization and recovery,
process and CPU controls, hardware monitoring, profiles, benchmarking, logs,
settings and Companion pairing. Hardware sensors require an enabled setting and
an active consumer. Benchmark results and game artwork must not be invented.
Riot software is subject to the repository's conservative non-mutation policy.
Desktop and Companion interfaces share domain owners rather than implementing
parallel system mechanics.

## Brand Commitments

FrameHub is a native Windows gaming tool. The requested redesign should be
distinctive, restrained, usable and suitable for demanding players, without
copying another product's branding or presenting fabricated measurements.

## Evidence on Hand

The current WPF views and ViewModels, architecture documentation, regression
tests and existing FrameHub assets are the source of product behavior. The
reference images supplied with the request are inspiration, not product data.

## Product Principles

- Show the actual state and explain unavailable data.
- Keep consequential system actions deliberate and recovery visible.
- Preserve existing functionality and native Windows interaction conventions.
- Keep information and actions understandable at practical window sizes.
